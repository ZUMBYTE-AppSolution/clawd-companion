# Claw’d Companion 0.7.3

Proses rilis macOS 0.7.3 menggunakan penandatanganan Developer ID otomatis dari Xcode. Setelah Apple menyelesaikan notarisasi, aplikasi akan tersedia dalam berkas DMG. Paket PKG juga akan tersedia jika penandatanganan penginstal telah disiapkan.

Untuk memperbarui dari versi lama bertanda tangan ad hoc, tutup Claw’d, buka DMG, lalu seret aplikasi ke folder Applications.
