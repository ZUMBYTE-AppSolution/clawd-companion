# Claw’d Companion 0.7.3

Für die Mac-Ausgabe von 0.7.3 ist die automatische Developer-ID-Signierung mit Xcode vorgesehen. Nach erfolgreicher Notarisierung durch Apple wird die App als DMG zum Download angeboten. Ein PKG kommt hinzu, wenn auch die Signatur für den Installer verfügbar ist.

Beim Wechsel von einer älteren Ad-hoc-Version Claw’d beenden, das DMG öffnen und die App nach „Programme“ ziehen.
