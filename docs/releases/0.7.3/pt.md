# Claw’d Companion 0.7.3

O processo de publicação da versão 0.7.3 para macOS usa a assinatura automática com Developer ID do Xcode. Após a notarização pela Apple, a aplicação ficará disponível num DMG. Haverá também um PKG se a assinatura do instalador estiver configurada.

Para atualizar a partir de uma versão anterior com assinatura ad hoc, encerre o Claw’d, abra o DMG e arraste a aplicação para a pasta Aplicações.
