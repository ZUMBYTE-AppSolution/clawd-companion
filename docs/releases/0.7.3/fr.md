# Claw’d Companion 0.7.3

Pour la version macOS 0.7.3, Xcode gère automatiquement la signature Developer ID. Une fois l’app notariée par Apple, elle sera proposée au format DMG. Un PKG sera également disponible si la signature du programme d’installation est configurée.

Pour passer d’une version antérieure avec signature ad hoc à cette version, quittez Claw’d, ouvrez le DMG et faites glisser l’app dans Applications.
