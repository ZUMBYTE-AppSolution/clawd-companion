# Claw’d Companion 0.7.3

macOS के लिए संस्करण 0.7.3 की रिलीज़ प्रक्रिया Xcode से अपने आप Developer ID हस्ताक्षर करती है। Apple का नोटरीकरण पूरा होने पर ऐप DMG में उपलब्ध होगा। इंस्टॉलर के लिए हस्ताक्षर की व्यवस्था होने पर PKG भी मिलेगा।

पुराने ऐड-हॉक संस्करण से अपडेट करने के लिए Claw’d बंद करें, DMG खोलें और ऐप को Applications फ़ोल्डर में खींचें।
