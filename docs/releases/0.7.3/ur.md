# Claw’d Companion 0.7.3

macOS کے لیے ورژن 0.7.3 کی ریلیز تیار کرتے وقت Xcode خودکار طور پر Developer ID سے ایپ پر دستخط کرتا ہے۔ Apple کی نوٹرائزیشن مکمل ہونے پر ایپ DMG فائل میں دستیاب ہوگی۔ انسٹالر پر دستخط کی سہولت ترتیب دی گئی ہو تو PKG بھی فراہم کیا جائے گا۔

پرانے ایڈ ہاک ورژن سے اپ ڈیٹ کرنے کے لیے Claw’d بند کریں، DMG کھولیں اور ایپ کو Applications فولڈر میں کھینچ کر رکھیں۔
