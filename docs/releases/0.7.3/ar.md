# Claw’d Companion 0.7.3

تستخدم عملية إصدار 0.7.3 لنظام macOS التوقيع التلقائي بهوية المطوّر Developer ID عبر Xcode. بعد توثيق التطبيق لدى Apple، سيتاح للتنزيل بصيغة DMG. وستتاح أيضًا حزمة PKG عند إعداد توقيع المثبّت.

للترقية من إصدار سابق بتوقيع محلي، أغلق Claw’d وافتح ملف DMG ثم اسحب التطبيق إلى مجلد التطبيقات.
