# Claw’d Companion 0.7.3

macOS-এর জন্য ০.৭.৩ প্রকাশের প্রক্রিয়ায় Xcode স্বয়ংক্রিয়ভাবে Developer ID দিয়ে অ্যাপে স্বাক্ষর করে। Apple-এর নোটারাইজেশন সম্পন্ন হলে অ্যাপটি DMG ফাইলে পাওয়া যাবে। ইনস্টলার স্বাক্ষরের ব্যবস্থা থাকলে PKG-ও দেওয়া হবে।

পুরোনো অ্যাড হক সংস্করণ থেকে আপডেট করতে Claw’d বন্ধ করুন, DMG খুলুন এবং অ্যাপটি Applications ফোল্ডারে টেনে আনুন।
