# Claw’d Companion 0.7.3

El proceso de publicación de 0.7.3 para macOS usa la firma automática con Developer ID de Xcode. Cuando Apple notarice la app, se ofrecerá en un DMG. También habrá un PKG si está configurada la firma del instalador.

Para actualizar desde una versión anterior con firma ad hoc, cierra Claw’d, abre el DMG y arrastra la app a Aplicaciones.
