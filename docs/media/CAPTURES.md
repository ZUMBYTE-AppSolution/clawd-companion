# About the captures

The macOS screenshots show Claw’d’s own English SwiftUI panels, captured from a local run of the app views. The overview uses synthetic session and weekly quotas. It shows what a paired browser can report. The update panel was opened without querying a release. The highscore view uses a local in-memory HTTP fixture for the account, ranking and active match. The names and scores in it are fictional.

The **Claude.ai activity replay** shows a local diagnostic console built for this recording. It is not a screenshot of the Claude.ai website. A fixture supplies visible browser status labels to the extension’s activity detector. The application’s authenticated request parser then validates the resulting messages, and its normal state handling chooses each pose. The approval and notification examples use synthetic event payloads. The replay shows a flipchart, research notes, file reading, a terminal, a drawing easel, an approval scroll and a pixel speech bubble.

The four **motion sheets** include every native desktop pose, each paired with its original menu bar animation. The full-color character is the desktop sprite. The smaller monochrome character is the menu bar version.

The **Virus Arena** video follows one unassisted, seeded game. It uses the native combat renderer, health bars, sprites and sound cues. The final edit jumps forward five minutes from the GIT gravestone to the revival animation. The scenery behind the transparent overlay is a presentation background.
